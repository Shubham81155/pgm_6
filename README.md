# Exp6 - Aesthetic Registration Form Demo

A modern, feature-rich Android registration application built with Kotlin and Material 3. This project demonstrates the implementation of various basic UI components within a polished "User Profile" interface.

## 🚀 Features

- **Comprehensive UI Components**: Utilizes `TextView`, `EditText` (TextInputLayout), `Button`, `ImageButton`, `CheckBox`, `ToggleButton`, and `RadioGroup/RadioButton`.
- **Material 3 Design**: Features a clean, card-based layout with a modern color palette (Deep Purple & Teal).
- **Interactive Form**:
    - **Live Summary**: A real-time summary card that updates as the user fills out the form.
    - **Date Picker**: Integrated `DatePickerDialog` for selecting a birth date.
    - **Password Toggle**: Built-in visibility toggle for secure password entry.
- **Enhanced Navigation**:
    - **Smooth Scrolling**: Floating Action Buttons (FABs) to jump instantly to the top or bottom of the long form.
- **Smart Validation**: Real-time email formatting checks and mandatory field verification.

## 🛠️ Technologies Used

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Theming) & XML Layouts
- **Design System**: Material Design 3
- **Min SDK**: 24 (Android 7.0)
- **Target SDK**: 37

## 📸 UI Overview

The app is organized into logical cards:
1. **Account Details**: Name, Email, and Password.
2. **Personal Info**: Gender selection and Date of Birth.
3. **Preferences**: Terms acceptance and newsletter toggle.
4. **Live Progress**: Real-time feedback on user inputs.

## ⚙️ How to Run

1. Clone the repository or open the project in **Android Studio**.
2. Sync the project with Gradle files.
3. Run the app on an emulator (e.g., Pixel 8) or a physical device.
